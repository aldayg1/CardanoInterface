# Support

## Bugs and features

Open an issue:
- GitLab (primary): https://gitlab.com/RefracticLabs/cardanointerface/-/issues
- GitHub mirror: https://github.com/aldayg1/CardanoInterface/issues

Include: backend used (Blockfrost/Koios/Ogmios+Kupo), network
(Mainnet/Preprod/Preview), steps to reproduce. Never paste mnemonics,
private keys, or passwords — support will never ask for them.

## Security vulnerabilities

Do NOT open a public issue. See [SECURITY.md](SECURITY.md) —
email security@refracticlabs.io, acknowledgment within 72 hours.

## Recovery help (stranded multisig)

Read the recovery section in [README.md](README.md) first, then open
an issue with your wallet type (Nami/Typhon/Lace/other) and export
format (CBOR hex / .cbor file / checkpoint / transaction). Response
target: 7 days, best effort — single-maintainer project.

## Self-help order

1. README setup + backend health check (menu option 13).
2. Test on Preprod before Mainnet.
3. Start with small amounts. See the risk notice in README.
